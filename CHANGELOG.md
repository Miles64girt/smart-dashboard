# История версий

Все заметные изменения проекта Smart Dashboard. Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [семантическому версионированию](https://semver.org/lang/ru/).

> ⚠️ Приложение проверено только на одном планшете — Huawei MediaPad T3 7 (BG2-U01), Android 7.0. На других устройствах не тестировалось, см. [docs/ru/TESTING.md](docs/ru/TESTING.md).

## 1.3 — публичный релиз

Первый публичный выпуск: личные данные убраны, настройки сведены в один конфиг, сборка больше не хранит секретов.

### Добавлено

- **`DeviceConfig.java`** — единый файл настроек: часовой пояс, город, координаты и автоопределение, расписание, яркость, беззвучный режим, стартовый список вещей, «Тетрадь из календаря», базовые размеры вёрстки.
- **Автоопределение города** по IP через wttr.in. Можно отключить и задать координаты и название города вручную.
- **Адаптивный масштаб вёрстки**: интерфейс масштабируется по `min(ширина/600, высота/1024)`, поэтому лучше выглядит на экранах с другим соотношением сторон.
- Документация на русском и английском языках: установка, сборка, адаптация, тестирование, архитектура, FAQ, ограничения.
- `PROMPT_RU.md` и `PROMPT_EN.md` — готовые промты для нейросети, если нужно подогнать вёрстку под свой экран.
- Обезличенные демонстрационные скриншоты в `docs/screens/`.

### Изменено

- **Список вещей по умолчанию теперь пуст.** Каждый добавляет свои пункты сам через «+ Добавить свой пункт»; личные вещи автора из кода удалены.
- **Часовой пояс по умолчанию — системный.** При необходимости задаётся явно в `DeviceConfig.TIME_ZONE` (например, `Europe/Moscow`).
- **Скрипты больше не привязаны к конкретной модели и серийному номеру планшета** — adb ищется автоматически, пакет и APK определяются по имени.
- **Ключ подписи генерируется локально** при первой сборке: `build/keystore.jks` и `build/keystore.properties` создаются автоматически, пароль случаен и в репозиторий не попадает.
- Переработана документация и скриншоты: ни города, ни реальных событий календаря, ни личных вещей.

### Удалено

- Личные данные автора из кода и документации: зашитый город, личный список вещей, серийные номера, пароль ключа подписи.

## 1.2 — вечерний список вещей

### Добавлено

- Вечернее окно-чек-лист в 20:00 (по умолчанию кроме субботы): центральная карточка на размытом фоне панели, отметки с зачёркиванием, долгое нажатие удаляет свой пункт.
- «+ Добавить свой пункт»: свои вещи сохраняются в настройках и не пропадают между днями.
- Анимация успеха: зелёная галочка, салют из частиц и автозакрытие окна примерно через 5,6 секунды.
- Пункт «Тетрадь (предметы из календаря на завтра)» — необязательный, по умолчанию выключен.
- Кнопки в правом нижнем углу: **≡** открывает список вручную, **⏻** показывает системное меню питания.
- Служба доступности — только для показа меню питания. Приложение ничего не читает и не нажимает за пользователя.
- При старте приложение переводит планшет в беззвучный режим (отключается в конфиге).

### Изменено

- Карточки вечернего списка получили прокрутку на случай, если пунктов много.
- Состояние «уже показано сегодня» и «всё отмечено» хранится по дате, чтобы окно не повторялось.

## 1.1 — устойчивость и работа без сети

### Добавлено

- Кэш последних данных погоды на диск: при отсутствии сети показывается прогноз с пометкой «Нет сети · данные ЧЧ:ММ».
- Мгновенное обновление при появлении сети (`CONNECTIVITY_ACTION`).
- Защита от частых повторов при ошибках загрузки: пауза растёт 1 → 2 → 4 → 8 → 16 → 30 минут.
- Ночной режим с приглушённой яркостью и надписью «касание — включить экран»; касание включает экран на 5 минут.
- Поддержка перевёрнутого портрета: переворот определяется по акселерометру, отрисовка поворачивается на 180°.

## 1.0 — первая рабочая версия

### Добавлено

- Информационная панель на весь экран: слева погода (текущая и ощущаемая температура, минимум/максимум, влажность, ветер, осадки, восход и закат), блок «Что надеть сегодня», справа — события календаря на сегодня.
- Погода из wttr.in (бесплатно, без ключа) с резервным источником Open-Meteo и кэшем.
- Календарь через системный `CalendarContract` — без пароля Google и без хранения токенов.
- Расписание: 08:00 — включить экран, 21:00 — ночной режим и выключение экрана.
- Автозапуск после перезагрузки (`BOOT_COMPLETED`) и восстановление расписания.
- Сборка без Gradle: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`.
- Полноэкранный режим и постоянное включение экрана в дневное время.

Об ограничениях каждой версии честно написано в [docs/ru/LIMITATIONS.md](docs/ru/LIMITATIONS.md). Порядок установки — [docs/ru/INSTALL.md](docs/ru/INSTALL.md).
