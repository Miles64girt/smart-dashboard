# Установка готового APK

Пошаговая инструкция для случая, когда исходники и сборка вам не нужны: скачать готовый файл, поставить его на планшет, выдать разрешения и проверить, что всё работает.

> ⚠️ **Проверено только на одном планшете.** Инструкция написана для Huawei MediaPad T3 7 (BG2-U01), Android 7.0, EMUI 5.1. Названия пунктов меню на других прошивках могут отличаться — ориентируйтесь по смыслу. Перед постоянным использованием проверьте приложение по [чек-листу](TESTING.md). Используете на свой риск.

## Что понадобится

- Планшет с Android **7.0 и новее** (в приложении `minSdk 24`). Root не нужен, загрузчик разблокировать не нужно.
- Файл `SmartDashboard-1.3.apk` — из папки [`apk/`](../../apk/) репозитория или со страницы [Releases](https://github.com/Miles64girt/smart-dashboard/releases).
- Для календаря — Google-аккаунт, добавленный в настройках Android. Если аккаунта нет, приложение всё равно запустится, просто правая половина будет пустой.
- Интернет на планшете — для загрузки погоды. Первый запуск без сети тоже работает: панель покажет «нет данных», пока сеть не появится.

## Шаг 1. Скачайте APK

Скачайте файл на планшет напрямую или перекиньте его с компьютера — по USB, через облако или мессенджер. Главное, чтобы файл оказался в памяти планшета и вы могли открыть его файловым менеджером.

Проверить имя просто: `SmartDashboard-1.3.apk`. Версия указана и в названии файла, и на странице релиза.

## Шаг 2. Разрешите установку из неизвестных источников

Android по умолчанию не даёт ставить приложения «с улицы». Разрешение выдаётся либо целиком, либо конкретному приложению, из которого вы открываете APK.

**Android 7.0 (чистый):**

1. Настройки → **Безопасность**.
2. Включите **Неизвестные источники**.
3. Подтвердите предупреждение.

**EMUI 5.1 / Huawei:**

1. Настройки → **Безопасность** → **Дополнительные настройки** → **Установка из внешних источников**.
2. Выберите файловый менеджер или браузер, которым будете открывать APK, и разрешите ему установку.

Можно пойти и коротким путём: откройте APK в файловом менеджере, и система сама предложит перейти в нужный раздел настроек кнопкой «Настройки» / «Разрешить».

> Не отключайте Play Protect глобально и не ставьте «разрешить всё подряд» на постоянной основе. Достаточно разрешения для одного файлового менеджера на время установки.

## Шаг 3. Установите APK

1. Откройте `SmartDashboard-1.3.apk` в файловом менеджере.
2. Нажмите **Установить**.
3. Если появилось окно Play Protect с текстом вроде «Приложение не проверено» или «Небезопасное приложение» — это обычное предупреждение для APK не из Google Play. Нажмите **Всё равно установить** (или «Установить без проверки»).
4. Дождитесь надписи «Приложение установлено» и нажмите **Открыть**.

Если установка прерывается с ошибкой подписи — на планшете уже стоит сборка, подписанная другим ключом. Удалите старую версию (см. [Удаление](#удаление-и-откат)) и повторите установку.

## Шаг 4. Выдайте разрешение на календарь

При первом запуске приложение попросит доступ к календарю. Разрешите его — иначе события на правой половине не появятся.

- Разрешение называется **Календарь** (`READ_CALENDAR`). Контакты, звонки, СМС, местоположение и другие данные приложению не нужны.
- Если случайно отказали: Настройки → **Приложения** → **Smart Dashboard** → **Разрешения** → **Календарь** → разрешить. Или Настройки → **Приложения** → значок шестерёнки → **Разрешения** → **Календарь**.
- После выдачи доступа события подтянутся в течение нескольких секунд, перезапуск не нужен.

> Приложение только **читает** события через системный `CalendarContract`. Пароль Google оно не запрашивает, OAuth-токены не хранит и ничего в календарь не пишет.

## Шаг 5. Включите службу доступности (по желанию)

Это нужно только для кнопки **⏻** в правом нижнем углу: она открывает штатное меню питания Android, где можно выбрать «Выключить» или «Перезагрузить».

1. Настройки → **Специальные возможности** (на EMUI может называться «Спец. возможности»).
2. Найдите в списке **Smart Dashboard**.
3. Включите службу и подтвердите предупреждение системы.

Без этой службы панель работает полностью, просто кнопка **⏻** покажет подсказку «Включите службу Smart Dashboard в Настройки → Специальные возможности» и откроет нужный раздел настроек.

> Служба доступности используется **только** для показа системного меню питания. Приложение не читает содержимое экрана, не нажимает кнопки и не следит за вашими действиями — в его конфигурации прямо запрещено чтение содержимого окон.

## Шаг 6. Разрешите автозапуск и снимите ограничения батареи

Android и особенно прошивки Huawei/EMUI любят «оптимизировать» приложения и не дают им запускаться самим. Чтобы панель открывалась после перезагрузки и будильники срабатывали вовремя, сделайте три вещи.

### 6.1. Запуск приложений (EMUI)

1. Настройки → **Батарея** → **Запуск приложений** (в разных версиях EMUI: «Защищённые приложения», «Диспетчер телефона» → «Автозапуск»).
2. Найдите **Smart Dashboard**.
3. Разрешите **автозапуск** (и, если есть, снимите галочку с «Управлять автоматически»).

### 6.2. Исключение из оптимизации батареи (стандартный Android)

1. Настройки → **Батарея** → меню (⋮) → **Оптимизация батареи**.
2. Выберите **Все приложения** → **Smart Dashboard**.
3. Установите **Не оптимизировать** / «Не ограничивать».

Если такого пункта нет, приложение всё равно работает — просто проверьте автозапуск после перезагрузки.

### 6.3. Проверка автозапуска

1. Перезагрузите планшет: **выключить → включить** или `adb reboot`.
2. Подождите 10–20 секунд после появления рабочего стола.
3. Панель должна открыться сама, на весь экран.

Если не открылась — вернитесь к пункту 6.1: чаще всего дело именно в настройках EMUI. Подробнее — в [FAQ](FAQ.md#не-запускается-после-перезагрузки).

## Шаг 7. Первый запуск

Что вы увидите:

- приложение открывается на весь экран, без строки состояния и кнопок навигации;
- слева сначала «нет данных», через 5–15 секунд появляется погода;
- справа — события календаря на сегодня, если аккаунт добавлен и события есть;
- если сети нет, внизу слева появится «Нет сети · данные ЧЧ:ММ» — это последний сохранённый прогноз.

Дальше панель живёт сама: погода обновляется примерно раз в 30 минут, календарь — раз в 5 минут, данные подтягиваются сразу при появлении сети.

## Шаг 8. Проверьте, что всё работает

Короткий чек-лист после установки:

- [ ] панель открылась и заняла весь экран;
- [ ] слева есть погода (температура, «Что надеть сегодня»);
- [ ] справа видны события на сегодня или половина пустая, если событий нет;
- [ ] кнопка **≡** открывает вечерний список вещей;
- [ ] список пустой, а «+ Добавить свой пункт» добавляет вашу вещь;
- [ ] кнопка **⏻** открывает меню питания (если включили службу доступности);
- [ ] после перезагрузки панель запустилась сама;
- [ ] при закреплённом «вверх ногами» планшете панель отображается правильно.

Полный список проверок и что делать при проблемах — в [TESTING.md](TESTING.md) и [FAQ.md](FAQ.md).

## Шаг 9. Добавьте свои вещи

Вечерний список в версии 1.3 по умолчанию **пустой** — так и задумано, чтобы в репозитории не было чужих личных вещей.

1. Нажмите **≡** в правом нижнем углу панели.
2. Нажмите «**+ Добавить свой пункт**».
3. Введите название, например «Ключи», и нажмите **Добавить**.
4. Пункт сохранится и будет появляться каждый вечер.

Удалить свой пункт: зажмите его примерно на секунду в вечернем списке — появится подсказка «Удалено: …». Пункты, добавленные вручную, можно удалять; стандартных пунктов в списке нет.

## Обновление

Обновляйте установкой поверх:

1. Скачайте новый APK.
2. Откройте его и нажмите **Обновить**.
3. Данные приложения (разрешения, ваши пункты списка) сохранятся.

Android разрешает обновление только поверх приложения с **той же подписью**. APK из этого репозитория подписан ключом автора, поэтому обновления из репозитория встают нормально. Если вы собирали приложение сами, подпись будет другой — поверх репозиторного APK такая сборка не встанет, потребуется удалить старую версию (и потерять настройки). Подробнее — в [BUILD.md](BUILD.md).

## Удаление и откат

Приложение ничего не меняет в системе: нет root, нет системных разделов, нет фоновых служб, кроме вашей же службы доступности (если включали).

1. Настройки → **Приложения** → **Smart Dashboard** → **Удалить**.
2. Подтвердите.

Или по USB:

```powershell
adb uninstall ru.home.dashboard
```

Вместе с приложением удаляются его настройки, кэш погоды, ваш список вещей, разрешение календаря и будильники расписания. Служба доступности отключается автоматически. Планшет возвращается к обычному поведению: экран больше не включается по расписанию, панель не запускается сама.

## Установка через ADB (необязательно)

Если на планшете включена отладка по USB и есть `adb`, всё можно сделать из PowerShell. Команды выполняются из корня репозитория.

```powershell
# 1. Установить (или обновить) APK
adb install -r .\apk\SmartDashboard-1.3.apk

# 2. Выдать разрешение на календарь
adb shell pm grant ru.home.dashboard android.permission.READ_CALENDAR

# 3. Исключить из оптимизации батареи (Doze)
adb shell dumpsys deviceidle whitelist +ru.home.dashboard

# 4. Запустить панель
adb shell am start -n ru.home.dashboard/.MainActivity

# 5. Проверить, что приложение на экране
adb shell dumpsys activity activities | Select-String mResumedActivity

# 6. Удалить
adb uninstall ru.home.dashboard
```

Службу доступности через ADB включать не стоит: на разных прошивках это работает по-разному. Надёжнее включить её руками, как в [шаге 5](#шаг-5-включите-службу-доступности-по-желанию).
